# 中文教程索引

这是一套**手把手**的部署实战教程。你不需要任何运维经验,但每一行命令都会告诉你"为什么"。

## 学习路线图

```
初级:一台服务器、一个域名、一条 HTTPS 网址
      │  我有一个能跑的 Node 项目,怎么放到互联网上?
      ▼
中级:推送即部署,失败自动回滚
      │  手动 deploy.sh 又慢又容易错,怎么自动化并且不出事故?
      ▼
高级:对比、量化与升级决策
         规模上来了:零停机?构建别影响线上?密钥泄露了怎么办?
```

## 阅读约定

- **【本地】** / **【服务器】**:每条命令都标注了执行位置。服务器命令默认以你的日常用户(教程中叫 `sam`)SSH 登录后执行,需要 root 时会写明 `sudo`。
- 代码块第一行如果是 `# 文件: path`,表示这是要创建/编辑的文件完整内容。
- ✅ **检查点**:章节末尾的自测清单,全部通过再进入下一章。
- 🧪 **动手实验**:强烈建议实际做一遍,教程记录的是"应该看到什么"。
- ⚠️ **警告**:可能把你自己锁在门外的操作(没错,真的会发生)。
- 每册开头的"前置检查"会告诉你需要准备什么(钱、时间、账号)。

## 我应该从哪开始?

- 从来没部署过任何东西 → **初级,从头开始**,不要跳。
- 已经会 systemd + Nginx + HTTPS,但部署靠手动脚本 → 过一遍**中级册开头的『前置自查清单』**,全都能答"是"就直接进**中级**。
- 已有完整 CI/CD,想优化零停机/凭证/灾备 → 用同一份自查清单检验,轻松通过则从**高级**开始。

## 常见问题

- **要花多少钱?** 一台最低配 VPS 约 $4–6/月(教程用完可删),域名约 $1–10/年。高级册的对比实验建议另开一台按小时计费的机器,用完即删。
- **教程的示例应用是 Node 的,我是 Python/Go/Java,怎么办?** 部署的骨架(用户/目录/systemd/切换/健康检查/回滚)与语言无关。每册末尾有"迁移到你自己的项目"清单;高级册第 11 章会用一个 Go 迷你应用完整演示迁移过程。
- **会不会把我自己的服务器搞坏?** 教程只在实验服务器上做破坏性实验,且每一步都标注了风险。涉及 SSH/防火墙的章节(P8 原则)特意安排了"锁死演练"。
- **和 `deploy-experiment-prompt.md` 什么关系?** 那是这套教程的设计源头(一套未验证的部署参考设计 + 13 条业界原则)。教程把它拆成了三级课程,原 prompt 中的每条假设(H1–H11)和原则(P1–P13)都会在课程中被证实或修正,索引见高级册第 10 章。
