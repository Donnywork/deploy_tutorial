# 中文教程索引

这是一套**手把手**的现代应用部署实战课程。你不需要任何运维背景，但课程里的每一条命令都会讲清楚背后的“为什么”。

## 学习路线图

```
初级：一台服务器、一个域名、一条 HTTPS 网址
      │  “我写好了一个能跑的 Node 项目，怎么把它安全地放到公网上？”
      ▼
中级：推送即部署，失败自动回滚
      │  “手动跑 deploy.sh 又慢又容易出错，怎么实现稳妥的自动化发布？”
      ▼
高级：实测对比、量化权衡与架构演进
         “业务规模上来了：如何实现零停机？构建怎样脱离线上机器？凭证泄露怎么防？”
```

## 阅读约定

- **【本地】** / **【服务器】**：每条命令前都明确标注了执行环境。未特别说明时，服务器命令默认以你的日常运维账号（教程中统一使用 `sam`）通过 SSH 登录后执行；需要提权的操作会显式写出 `sudo`。
- 若代码块首行标注了 `# 文件: path`，代表该代码块是对应文件的完整内容，可直接创建或覆盖写入。
- ✅ **检查点**：每章末尾的阶段性自测清单。请务必逐项验证通过后再进入下一章。
- 🧪 **动手实验**：强烈建议亲手操作一遍的破坏性或验证性实验，教程中详细记录了每一步的预期现象。
- ⚠️ **警告**：稍有不慎就可能把你自己锁在服务器门外的高危操作（请严格按防护步骤执行）。
- 每册开篇均附有**前置准备清单**，提前说明所需的预算、耗时与账号准备。

## 遇到卡点？随时呼叫 AI 助教

本仓库原生支持 **AI 助教模式**：使用 Claude Code、Cursor、GitHub Copilot 等任意支持读取仓库上下文的 AI 工具**打开本仓库根目录**，直接用自然语言提问即可。根目录下的助教协议（`AGENTS.md`）会确保 AI 助教遵循以下教学规范：

1. **精准定位进度**：先确认你当前所处的册别与章节（若无法从上下文推断，每次最多只追问一句话，绝不连环盘问）；
2. **一次只走一步**：每条回复只给出一项操作指令，明确标注执行位置与预期输出，等你贴回实际运行结果后再推进下一步；
3. **严守阶段边界，绝不剧透**：当你问及后续章节才会引入的高级概念时，助教只会给出简明的一句话解释，并指明具体会在哪一册哪一章深入展开，避免因概念超载打乱当前节奏；
4. **基于排错库系统化诊断**：遇到报错时，优先匹配内置排错知识库（`ai/troubleshooting.md`，涵盖 T-01 至 T-32 典型故障），按标准排查链路逐步引导，授人以渔；
5. **安全底线**：绝不索要任何真实私钥或生产密码；涉及破坏性操作前，必定先确认你处于实验环境并给出防锁死保护步骤。

## 我该从哪一册开始？

- **从未独立部署过任何线上服务** → 请从**初级册第一章**稳步开始，切勿跳读。
- **已熟练掌握 systemd + Nginx + HTTPS，但日常发布仍靠手动执行脚本** → 请先对照**中级册开篇的“前置自查清单”**逐项核验；若全部达标，可直接从**中级册**切入。
- **已有成熟的自动化 CI/CD 流水线，希望攻克零停机发布、凭证安全与容灾演练** → 同样先快速过一遍中级册的前置自查清单，确认基础扎实后直接进入**高级册**。

## 常见问题

- **学完整个课程大概需要多少花费？** 租用一台入门级 VPS 约 $4–6/月（支持按小时计费，学完随时销毁），注册一个练手域名约 $1–10/年。高级册的压测与对账实验建议临时加开一台按量计费的机器，实验结束即刻释放，成本极低。
- **教程的演示项目用的是 Node.js，但我平时写 Python / Go / Java，这套方案适用吗？** 完全适用。本课程构建的部署骨架（多用户权限隔离、版本化目录布局、systemd 守护、原子软链切换、深度健康检查与一键回滚）与编程语言无关。每册末尾均配有“迁移到你自己的项目”实战清单；高级册第 11 章更使用一个纯 Go 编写的迷你服务，完整演示了跨语言迁移的全过程。
- **跟着做实验会不会把我的服务器搞崩？** 所有高风险破坏性实验均设计在独立的实验服务器上进行，且每一步都提前标明了影响范围与回退手段。在涉及 SSH 与防火墙加固的章节中，我们还专门设计了安全的“防锁死演练”，确保你在真正上生产前掌握自救技能。
- **需要死记硬背教程里的编号或专有术语吗？** 完全不需要。所有架构取舍都会转化为直白的工程常识（例如“一次构建，到处部署”、“未经演练的备份等于没有备份”），并标注对应的章节出处。教程还在开篇坦诚列出了各阶段的架构假设（例如“当前备份可能存在盲区”、“浅层健康检查可能会说谎”），随后在后续章节中通过实验逐一验证并填补这些漏洞，最终在高级册第 10 章完成全局复盘。
